AgentPress is an account-based pipeline builder that turns stored research feeds into generated content. Accounts connect research sources — YouTube channels, subreddits, RSS/Atom feeds — and define multi-agent pipelines where each agent has its own system prompt, user prompt, and output. Prompts interpolate variables and prior agent outputs at run time, and research feed summaries drop straight into a prompt with compact slug references like {ziptrader.summary}. Runs execute asynchronously and can publish the finished content straight to WordPress over the REST API.

The research layer is decoupled from pipeline execution on purpose: runs never call YouTube, Reddit, or an RSS endpoint directly, they read from stored ResearchItem/ResearchSummary data collected separately. Every remote fetch — including failed 403/429/500 responses — sits behind a shared one-hour cache so a pipeline run can't hammer a provider. The API contract is OpenAPI-first: the spec is the source of truth, and the frontend's SDK types are generated from it and checked for drift.
