Agentpress runs the agent workflow in the browser instead of on a server. Each user supplies their own API key, so LLM calls and the cost of running them stay on the client. The authoring canvas builds a DAG of agent steps that serializes to JSON, and a published workflow gets a shareable URL that anyone can run with their own inputs and credentials, watching each step execute in real time.

I designed the publishing model, built the node-graph authoring canvas, and implemented the client-side agent runtime along with a versioned workflow registry. Making the execution model work entirely in the browser, without a server holding state, was the main technical problem to solve.

Tech Stack
React Node.js LLM (Claude / GPT-4) PostgreSQL Tool calling API Serverless fns Node graph canvas
The Numbers
$0 platform cost — users supply their own API keys
DAG execution model — branch, merge, parallel steps
1 URL to share a fully runnable agent workflow
0 local setup required to run a published workflow
