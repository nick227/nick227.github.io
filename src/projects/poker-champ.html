Poker Champ is a real-time multiplayer Texas Hold'em platform: Colyseus rooms run the authoritative game state — the Dealer engine, betting rules, side-pot math, and hand evaluation — while a shared Zod-schema contract keeps the server and an Expo client (iOS, Android, and Web from one codebase) speaking the same protocol. Persistent seats let a player disconnect and rejoin within a 60-second grace period without losing their stack, and a state machine drives automatic street transitions and auto-actions for disconnected players so a hand never stalls waiting on someone who dropped.

Tables can be filled out with AI opponents rather than left short-handed — the bot catalog defines named personas with distinct playstyles rather than one generic "AI": Chaos Carl and Loose Lucy play unpredictably, Nash Nate is tight-aggressive, Fiona Foldsworth folds tight and passive, Trent Tiltley plays loose-aggressive, and Callie Doyle rounds out loose-passive. An ai_v1 brain type is wired in for a fully model-driven bot alongside the rule-based ones. I built the full system — engine, room logic, bots, the economy/cashier layer with atomic buy-in and cash-out, and hand history logging for every action and payout.
