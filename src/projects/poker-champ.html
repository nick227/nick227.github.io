The game server is the single source of truth — clients render only what the server confirms, with no optimistic updates that could put players out of sync. Decks are Fisher-Yates shuffled with a cryptographic random seed, and the 7-card hand evaluator uses lookup tables for sub-microsecond showdown resolution. Tournament brackets rebalance automatically as tables empty.

I designed and built the full application — game server, hand evaluator, tournament engine, and the React client. A single hand of Hold'em has hundreds of valid state paths once you account for non-deterministic deals, concurrent player actions, and reconnects, which made testing the largest part of the work.
