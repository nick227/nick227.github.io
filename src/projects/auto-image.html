A seed prompt is decomposed into variable dimensions — subject, environment, lighting, color grading, style, mood — and each generation job samples from that parameter space instead of repeating the same settings. A quality scoring pipeline ranks outputs on aesthetic and technical metrics, so only the strongest results are left for a person to review.

I designed the parameter mutation model, built the GPU queue manager, wrote the quality scoring heuristics, and built the review interface. The project came out of a real need — generating hundreds of distinct images for content assets, not near-duplicates of the same one.
