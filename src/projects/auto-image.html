The core idea is a term placeholder system: a prompt like a $animal in $lighting, $style gets parsed for $word tokens, and each one is swapped for a random pick from that term's stored list of variants — so one saved prompt template produces a different, non-repeating image every run instead of the same composition over and over. Terms live in their own database table and get managed through a dedicated terms UI: search existing terms, add new ones, or let AI generate a starter set of variants for a term that doesn't exist yet. Inline custom lists like [red,blue,green] work the same way without needing a saved term at all.

On top of that sits batch generation: up to 10 images per run, each one re-rolling its own placeholders independently, queued with per-user rate limiting and retried with exponential backoff before routing to whichever AI provider is active — OpenAI DALL-E, Dezgo, or Google Vertex Imagen — behind one shared provider interface. Credits are metered per generation and sold through Stripe Checkout, and an admin panel controls which providers/models are live and what they cost, without a redeploy.
