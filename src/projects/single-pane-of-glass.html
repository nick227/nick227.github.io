The system is built on a source-adapter pattern — each data provider (APM, log aggregator, infra metrics, business KPIs) implements a normalizer that maps its payloads to a canonical event schema. A Node.js aggregation service fans events out over WebSocket to a React dashboard that can render any combination of panel types without knowing what's behind each adapter. Adding a new data source means writing one adapter, nothing else.

I designed the adapter interface, built the aggregation service, and implemented the widget rendering engine on the frontend. The ops team shaped the widget library through ongoing feedback, and I turned those requirements directly into production code.
