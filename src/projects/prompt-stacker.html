Prompt Stacker is a visual builder for chaining LLM prompts into a pipeline, so the output of one step becomes the input to the next instead of prompts running in isolation. The builder presents a vertical stack of nodes, each with its own input, system prompt, and a transformation function applied to the output before it passes downstream. Stacks execute as a DAG, so nodes can branch and merge rather than running strictly in sequence, and each node can target a different provider — GPT-4, Claude, or a local model — within the same pipeline.

I designed and built the tool end to end — the node-based builder, a step-by-step debugger for inspecting raw API responses at each stage, and a JSON export format that lets a finished stack be shared and re-imported by anyone with the tool. Most complex LLM tasks break down into a planning step, an execution step, a review step, and a formatting step; Prompt Stacker made that structure visible and testable instead of managed in someone's head or a scattered doc.
