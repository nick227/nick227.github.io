The tool captures three screen coordinates — input, submit, and accept — then drives a loop of timed clicks and clipboard pastes against whatever window matches a configured title pattern. Start delay, wait time between submissions, and a cooldown after each response are all configurable, and a DPI-aware capture step keeps coordinates accurate on high-resolution displays. The documentation is written around Cursor, but nothing in the automation loop is Cursor-specific — matching windows by title pattern means it can drive any application that needs timed clicking and pasted text.

I use it to feed a stack of prompts into an AI IDE one at a time: paste a prompt, wait for a response, click accept, move to the next. Pause, skip, retry, and cancel controls let me step in mid-run without restarting the stack, and settings and coordinates persist between sessions so a target application doesn't need to be re-captured every time. It's packaged with PyInstaller into a standalone executable, so it runs without a Python environment installed.
