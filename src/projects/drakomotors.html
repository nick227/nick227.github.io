The site uses scroll-driven hero sequences and a real-time vehicle color configurator, built in vanilla JavaScript without a framework. Scroll animations are tied to IntersectionObserver rather than timers, and the configurator swaps CSS custom properties on a high-resolution render without touching the DOM. Mobile LCP stayed under two seconds, using AVIF images with a WebP fallback and no layout shift on the configurator swap.

I led frontend architecture for the marketing site, covering performance, the animation system, and the configurator. The site launched alongside an auto show reveal, so load time and visual stability under traffic were fixed constraints from the start.
