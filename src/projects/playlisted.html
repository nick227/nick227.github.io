Playlisted is a full-stack music discovery and creator platform — editorial homepage rows, charts, unified search, favorites, and a persistent bottom player with queue. Creators get Studio uploads, cover art, collections, playback analytics, and canonical playlist URLs at /@username/slug. Playlist types cover albums, mixes, podcast channels, and releases, not only the usual chill-vibes dump.

The spine is contract-first: openapi/openapi.yaml drives an Express API validated against the spec and a generated TypeScript client SDK for the React SPA. Prisma and MySQL own the data. Production is two Railway services — web/API serving the built SPA, plus a subtitle worker that drains jobs through Modal — with Google auth, role-based admin tools, and R2 when media has to leave the web container.

Tech Stack
React 19 + Vite Express + OpenAPI Prisma + MySQL Generated client SDK Google OAuth Railway Modal subtitles Cloudflare R2
