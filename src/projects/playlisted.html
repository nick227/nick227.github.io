The hardest technical problem was matching the same song across services — Spotify and Apple Music assign different IDs to the same track. A fuzzy matching algorithm resolves identity using title, artist, and duration. The social graph models follow relationships and activity feeds, so users could see what people they followed were playing. At the time, few tools supported playlists that mixed tracks from both services.

I designed and built the platform on my own — API integrations, the social graph data model, real-time features, and the matching algorithm. A small community of music enthusiasts used it early, and their feedback shaped which features shipped.
