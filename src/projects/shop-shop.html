The OpenAPI schema is the source of truth — frontend and backend types are generated from it instead of written by hand, so a breaking API change fails at compile time instead of shipping silently. Zod validates every runtime boundary, and Stripe handles payment capture with an automatic split between the platform and shoppers.

I designed the schema-first API architecture, built the OpenAPI spec, wired up the type generation pipeline, and implemented the customer app, courier app, pricing engine, and Stripe integration. Committing to the type system early meant more upfront setup, but it shaped every layer of the project afterward.
