Shop-Shop is a DoorDash-style local kitchen and restaurant delivery marketplace. Customers discover food through a scored River feed, vendors run stores and teams, affiliates earn commissions, riders fulfill in-house jobs, and admins keep money and ops honest. One deploy serves several role products that share inventory, orders, and payouts.

It is a pnpm monorepo with contract-first TypeScript end to end: Zod schemas and OpenAPI generate the client SDK, Fastify owns the API and WebSockets, Prisma talks to MySQL, and the React + Vite app consumes the same types. Stripe Connect handles vendor and affiliate payouts. I designed the architecture and built the marketplace spine — roles, River discovery, order state, realtime tracking, and the generation pipeline that keeps CRUD and custom delivery logic on one contract.
