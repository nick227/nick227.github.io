Paste in a raw story, pick an art style, and a five-stage chain turns it into a synced storyboard: the script splits into scene fragments, each fragment becomes narration/dialogue prose, that collapses into a caveman-simple present-tense action beat (5–24 words), the beat expands into a camera-agnostic visual prompt that folds in continuity from neighboring shots plus up to 14 character/world reference images, and that prompt renders a keyframe image and an animated clip. Text and images default to Gemini's flash models, with OpenAI, Dezgo, and a local Fooocus/SDXL fallback available per generation. Voice runs through Piper for free neural TTS, ElevenLabs for cloud voices, or a zero-shot Spark-TTS cloning daemon that reuses a cloned voice across storyboards.

The system is a monorepo split across five independently deployed services — the Express web app plus four Python/FastAPI microservices on Modal for voice cloning, free-tier TTS, SDXL image generation, and WhisperX alignment — each with separate dev/prod environments so a routine push to main never touches what's serving live traffic. I built the storage boundary underneath it: committed media goes through a BlobStore abstraction (local disk today, optional dual-write to R2) while a separate AssetMaterializer handles the ephemeral file paths providers need, so generation code never touches raw disk paths directly. Autosave uses monotonic revision locks to catch conflicting edits, and Stripe Checkout drives a credit-based billing model with an admin pricing panel.
