The main engineering problem was streaming large DJ mixes — 60 to 90 minutes long — with smooth, seekable playback. Most hosting setups don't handle HTTP byte-range requests correctly, so I built a streaming endpoint that does, letting the browser's audio player seek to any point in a multi-hundred-megabyte file without downloading the whole thing first.

Crunkbox came out of a music community I was part of. I built the full platform — artist profiles, event calendar, community tools, and the streaming infrastructure — and had a direct line to the people using it, since I was one of them.
