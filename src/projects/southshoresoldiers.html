The main engineering challenge was the CMS — it needed to be simple enough for non-technical coaching staff to update rosters and post recaps without touching code, while the public site stayed polished. The data model handles seasonal roster changes, game history, and media content without conflicts.

I built the full site — public frontend, admin CMS, API, and data model. Coaching staff needed to be able to keep the site current on their own, so adoption by non-technical users was the main thing I was checking for after launch.
