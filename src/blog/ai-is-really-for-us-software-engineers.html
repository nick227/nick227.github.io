After tens of thousands of hours with generative AI, I keep landing on the same conclusion: it is best at writing code.

Maybe that is just me. I see more value in code than in Excel functions or emails. And honestly, AI is still not a great writer. That is obvious when it tries to write songs or jokes. The rhythm is off. The punchline arrives late or not at all. The prose sounds finished until you read it twice.

Code is different. It is fantastic at it.

AI has knocked down the syntax barriers. You no longer spend half your day remembering the exact shape of an API or the right flag for a tool you use once a quarter. That used to be a tax on every programmer. Now it is mostly gone.

We still want experience to be valuable. There is still a gulf of knowledge that vibe coding is not using. Taste, architecture, failure modes, what to leave out. The model will generate a path. It will not always generate the right one.

Even so, we are all vibe coding now. If you are not, you are either writing prototypical code or taking a very long time to get something mature. The people who pretend otherwise are usually slower, not more careful.

The whole world is still buzzing about AI. Little do they know: coders made this for other coders. You guys can try to use it too, I guess.
